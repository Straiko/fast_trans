# Olympus — Текстовый и голосовой переводчик

Десктопное приложение для мгновенного перевода текста и голосового ввода с возможностью AI-улучшения текста для нейросетей.

## Возможности

| Возможность | Описание |
|-------------|----------|
| **Перевод текста** | Выделите текст → нажмите горячую клавишу → получите перевод |
| **Голосовой ввод** | Скажите → речь распознаётся, переводится и вставляется |
| **AI-улучшение текста** | Оптимизирует текст для лучшего понимания нейросетью |
| **Исправление ошибок распознавания** | AI исправляет ошибки голосового распознавания перед переводом |
| **Автозамена** | Автоматически заменяет выделенный текст на перевод |
| **Восстановление буфера** | Исходное содержимое буфера восстанавливается после автозамены |
| **Уведомления в трее** | «Перевод вставлен» / «Перевод скопирован» |
| **Окно настроек** | Горячие клавиши, языки, микрофон, AI-провайдер |
| **Системный трей** | Работает в фоновом режиме |

## Быстрый старт: Установка и Запуск

Приложение может быть установлено автоматически в портативном режиме (без прав администратора) или вручную.

### 🚀 Способ 1: Windows Автоустановка (Портативная, без админки)
Самый простой способ запустить Olympus на Windows. Не требует установки Python в систему или наличия Git.

1. Скачайте файл автоустановщика [`install_portable.bat`](https://github.com/Straiko/fast_trans/releases/latest/download/install_portable.bat)
2. Запустите его двойным щелчком мыши.
3. Скрипт в фоновом режиме:
   - Создаст рабочую папку `C:\Olympus`
   - Скачает официальный чистый **портативный Python** (не загрязняет систему и реестр)
   - Развернет исходный код приложения в `C:\Olympus\fast_trans`
   - Установит все необходимые библиотеки через `pip`
   - Автоматически запустит Olympus.

**Как запускать приложение в дальнейшем:**
Для последующих запусков просто выполните команду ниже (или создайте ярлык на этот файл):
```cmd
C:\Olympus\python\python.exe C:\Olympus\fast_trans\main.py
```

### 💻 Способ 2: Ручная установка (Windows, Linux, macOS)
Если вы хотите установить приложение классическим способом в виртуальное окружение:

#### 1. Подготовка системных зависимостей
* **Linux (Ubuntu/Debian)** (необходимо для захвата микрофона и глобальных горячих клавиш):
  ```bash
  sudo apt-get update
  sudo apt-get install -y portaudio19-dev python3-pyaudio libxkbcommon-x11-0
  ```
* **macOS**:
  ```bash
  brew install portaudio
  ```
* **Windows**: Системные зависимости не требуются, все библиотеки ставятся через pip.

#### 2. Клонирование и установка зависимостей
Запустите в терминале/командной строке:
```bash
# Клонируем репозиторий
git clone https://github.com/Straiko/fast_trans.git
cd fast_trans

# Создаем виртуальное окружение
python3 -m venv venv
# Активируем его (Linux/macOS):
source venv/bin/activate
# Или в Windows (PowerShell):
# .venv\Scripts\Activate.ps1

# Обновляем установщик пакетов и ставим зависимости
pip install --upgrade pip
pip install -r requirements.txt

# Запускаем приложение
python main.py
```

После запуска Olympus свернется в **системный трей** (рядом с часами) и откроет окно начальных настроек.

## Использование

### Перевод выделенного текста

1. Выделите текст в **любом** приложении
2. Нажмите **`Ctrl+Shift+T`** (по умолчанию)
3. Текст переводится и автоматически заменяется
4. Исходное содержимое буфера восстанавливается

### Голосовой ввод

1. Нажмите **`Ctrl+Shift+V`** (по умолчанию)
2. Говорите в микрофон — запись остановится автоматически после паузы
3. Откроется окно проверки с распознанным текстом
4. Выберите **"Fix & translate"** (с AI-исправлением) или **"Translate as-is"** (как есть)
5. Перевод вставляется в активное поле

### Настройки

- Правый клик по иконке в трее → **Settings**
- Навигация по разделам: горячие клавиши, перевод, микрофон, API
- Все изменения применяются мгновенно без перезапуска
- **Cancel** откатывает все изменения с момента открытия окна

## Установка на Linux

### Голосовой ввод

```bash
# Ubuntu/Debian
sudo apt-get install portaudio19-dev python3-pyaudio
pip install pyaudio

# Fedora
sudo dnf install portaudio-devel
pip install pyaudio
```

### Глобальные горячие клавиши без root

Приложение использует `pynput` для глобальных горячих клавиш на Linux без root.

```bash
pip install six pynput
```

Если `pynput` недоступен, горячие клавиши и автозамена не сработают. Приложение покажет предупреждение в трее.

### Проблемы SSL с pip

```bash
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org six pynput
```

## 📦 Сборка в один файл (.EXE) для Windows

Вы можете скомпилировать приложение в один независимый исполняемый файл `.exe`, который можно запускать на любом компьютере с Windows (установка Python или библиотек конечному пользователю не потребуется).

Сборка должна производиться на ОС Windows:

1. Откройте терминал **PowerShell** в папке проекта.
2. Если в вашей системе заблокирован запуск внешних скриптов, разрешите его для текущей сессии:
   ```powershell
   Set-ExecutionPolicy Bypass -Scope Process -Force
   ```
3. Запустите готовый скрипт автоматической сборки:
   ```powershell
   .\build_windows.ps1
   ```

**Что делает скрипт автоматически:**
* Создает изолированное виртуальное окружение `.venv` (если его нет).
* Обновляет базовые инструменты сборки (`pip`, `wheel`, `setuptools`).
* Устанавливает все зависимости из `requirements.txt` и сам `PyInstaller`.
* Очищает папки от прошлых сборок (`build/` и `dist/`).
* Компилирует код приложения в один оптимизированный файл, вшивая в него новый премиальный стеклянный логотип (`icon.ico` и `icon.png`).

**Результат сборки:**
Готовый исполняемый файл появится в папке `dist\Olympus.exe`. Его можно переносить на другие ПК и использовать автономно!

## Расположение конфига

| ОС | Путь |
|----|------|
| Linux | `~/.config/olympus/config.json` |
| Windows | `%APPDATA%\olympus\config.json` |

Старый путь (`~/.text_translator_config.json`) автоматически мигрируется при первом запуске.
